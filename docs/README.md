# Documentation

Long-lived product and contributor documentation belongs in this directory.

- [Language packs](./LANGUAGE-PACKS.md) describes the validated translation format and installation workflow.
- [Palworld setting reference](./PALWORLD-SETTINGS-REFERENCE.md) defines the evidence standard and research record for administrator-facing setting help.
- [UI workflow design](./UI-WORKFLOW-MAP.md) records the operator workflows retained from the original manager.

Repository entry points, policies, licenses, and agent instructions remain at the repository root. Temporary implementation checklists and completed build audits belong in the ignored `.scratchpad/` directory rather than the maintained documentation set.
